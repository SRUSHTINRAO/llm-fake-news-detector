# 🧠 LLM Fake News Detector

An AI-powered system that analyzes news credibility using LLM-based reasoning.

## 🚀 Features
- Classifies news as Real, Fake, or Uncertain
- Provides explanation for predictions
- Works across domains (news, social media, entertainment)
- FastAPI backend with interactive UI

## 🛠 Tech Stack
- Python
- FastAPI
- Groq (LLaMA 3.1)

## ⚠️ Limitation
This system performs credibility analysis, not real-time fact verification.
